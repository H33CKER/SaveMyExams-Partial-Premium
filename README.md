# SaveMyExams - Partial Premium

A lightweight Tampermonkey userscript that allows viewing an unlimited amount of revision notes and hides the annoying premium pop-ups and buttons.

---

## Overview

This userscript runs on SaveMyExams pages. It removes selected interface elements, clears several local view counters and limit-wall elements inside tab panes.

---

## Features

- Removes the “Download notes” button and plan link
- Clears selected SaveMyExams view counters on page load and periodically while the page is open
- Handles dynamically loaded content
- Lightweight and requires no configuration

---

## Installation

### 1. Install Tampermonkey

You need the Tampermonkey extension:

- Chrome / Edge: https://www.tampermonkey.net/
- Firefox: https://www.tampermonkey.net/

---

### 2. Install the script

Click the link below to install:

👉 https://raw.githubusercontent.com/H33CKER/SaveMyExams-Partial-Premium/main/SaveMyExams-Premium.user.js

Tampermonkey will open → click **Install**.
